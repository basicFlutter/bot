# ربات معاملاتی هوشمند (Smart Trading Bot)

این ربات معاملاتی برای شناسایی و معامله بر اساس الگوهای اصلاح قیمت (Retracement) در بازار طراحی شده است. ربات به طور خاص بر روی شناسایی لگ‌های صعودی و نقاط ورود مناسب تمرکز دارد.

## پارامترهای ورودی

### تنظیمات اصلی
- **TimeFrame**: تایم‌فریم معاملاتی (پیش‌فرض: M5)
  - فقط تایم‌فریم‌های M5 و M15 پشتیبانی می‌شوند
  - تعیین بازه زمانی برای تحلیل قیمت

- **FastMA_Period**: دوره میانگین متحرک سریع (پیش‌فرض: 10)
  - برای شناسایی روندهای کوتاه‌مدت
  - هرچه عدد کوچکتر باشد، حساسیت به تغییرات قیمت بیشتر می‌شود

- **SlowMA_Period**: دوره میانگین متحرک کند (پیش‌فرض: 21)
  - برای شناسایی روندهای بلندمدت‌تر
  - معمولاً باید بزرگتر از FastMA_Period باشد

- **RSI_Period**: دوره RSI (پیش‌فرض: 14)
  - برای شناسایی شرایط اشباع خرید و فروش
  - دوره استاندارد 14 است، اما می‌تواند بر اساس نیاز تنظیم شود

- **Risk_Percent**: درصد ریسک از کل سرمایه (پیش‌فرض: 2.0)
  - تعیین می‌کند چه درصدی از سرمایه در هر معامله ریسک شود
  - مقدار پیشنهادی بین 1% تا 3% است

- **RSI_Upper**: سطح اشباع خرید RSI (پیش‌فرض: 70)
  - قیمت در این سطح یا بالاتر، اشباع خرید محسوب می‌شود
  - هرچه عدد بزرگتر باشد، سیگنال‌های فروش کمتر می‌شوند

- **RSI_Lower**: سطح اشباع فروش RSI (پیش‌فرض: 30)
  - قیمت در این سطح یا پایین‌تر، اشباع فروش محسوب می‌شود
  - هرچه عدد کوچکتر باشد، سیگنال‌های خرید کمتر می‌شوند

- **Magic_Number**: شماره منحصر به فرد ربات (پیش‌فرض: 123456)
  - برای شناسایی معاملات این ربات
  - باید برای هر ربات متفاوت باشد

- **ShowBacktest**: نمایش نتایج بک‌تست (پیش‌فرض: true)
  - اگر فعال باشد، نتایج بک‌تست در ترمینال نمایش داده می‌شود

- **BacktestBars**: تعداد کندل‌های بک‌تست (پیش‌فرض: 1000)
  - تعیین می‌کند چند کندل اخیر برای بک‌تست استفاده شود
  - هرچه عدد بزرگتر باشد، دوره بک‌تست طولانی‌تر می‌شود

### تنظیمات تشخیص نقاط محوری
- **InpCheckBarsM5**: تعداد کندل‌های بررسی برای M5 (پیش‌فرض: 3)
  - تعیین می‌کند چند کندل قبل و بعد برای تشخیص سقف و کف بررسی شود
  - در تایم‌فریم M5 استفاده می‌شود

- **InpCheckBarsOther**: تعداد کندل‌های بررسی برای سایر تایم‌فریم‌ها (پیش‌فرض: 2)
  - مشابه InpCheckBarsM5 اما برای تایم‌فریم‌های دیگر
  - معمولاً عدد کوچکتری نسبت به M5 است

### تنظیمات حرکت صعودی
- **InpMinMove**: حداقل حرکت قیمتی (پیپ) (پیش‌فرض: 5.0)
  - حداقل حرکت مورد نیاز برای تشخیص روند صعودی
  - هرچه عدد کوچکتر باشد، روندهای کوچکتر هم شناسایی می‌شوند

- **InpMaxConsecutiveDownBars**: حداکثر کندل‌های نزولی متوالی (پیش‌فرض: 7)
  - تعیین می‌کند چند کندل نزولی متوالی مجاز است
  - هرچه عدد بزرگتر باشد، روندهای پرنوسان‌تر هم قابل قبول هستند

- **InpPullbackLimit**: حداکثر درصد اصلاح مجاز (پیش‌فرض: 0.5)
  - حداکثر درصد مجاز برای اصلاح قیمت
  - مقدار بین 0.0 تا 1.0 (50% = 0.5)

- **InpMinUpBarsPercent**: حداقل درصد کندل‌های صعودی (پیش‌فرض: 0.25)
  - حداقل درصد کندل‌های صعودی مورد نیاز
  - مقدار بین 0.0 تا 1.0 (25% = 0.25)

### تنظیمات لگ اصلاحی
- **InpMinUpMove**: حداقل حرکت صعودی برای لگ (پیپ) (پیش‌فرض: 15.0)
  - حداقل حرکت صعودی مورد نیاز برای یک لگ معتبر
  - باید بزرگتر از InpMinMove باشد

- **InpTargetRetracement**: درصد اصلاح هدف (پیش‌فرض: 50.0)
  - درصد اصلاح مورد انتظار برای یک لگ معتبر
  - معمولاً بین 50% تا 61.8% است

- **InpRetracementTolerance**: تلرانس مجاز برای درصد اصلاح (پیش‌فرض: 10.0)
  - محدوده مجاز انحراف از درصد اصلاح هدف
  - مثلاً ±10% برای هدف 50%

- **InpMaxBarsInUptrend**: حداکثر تعداد کندل در روند صعودی (پیش‌فرض: 40)
  - حداکثر تعداد کندل مجاز در یک روند صعودی
  - هرچه عدد بزرگتر باشد، روندهای طولانی‌تر هم قابل قبول هستند

### تنظیمات زمانبندی
- **InpLookBackDays**: تعداد روزهای بررسی به عقب (پیش‌فرض: 20)
  - تعیین می‌کند چند روز به عقب برای تحلیل بررسی شود
  - هرچه عدد بزرگتر باشد، داده‌های تاریخی بیشتری بررسی می‌شود

## نکات مهم
1. تنظیمات باید بر اساس ویژگی‌های نماد معاملاتی و تایم‌فریم انتخاب شده بهینه شوند.
2. پارامترهای مربوط به حرکت قیمت (InpMinMove و InpMinUpMove) باید متناسب با نوسان نماد تنظیم شوند.
3. درصدهای اصلاح (InpTargetRetracement و InpRetracementTolerance) بر اساس الگوهای تکنیکال کلاسیک تنظیم شده‌اند.
4. تعداد کندل‌های بررسی (InpCheckBarsM5 و InpCheckBarsOther) باید متناسب با نویز بازار تنظیم شوند.

## پیشنهادات بهینه‌سازی
1. برای نمادهای پرنوسان: افزایش InpMinMove و InpMinUpMove
2. برای روندهای قوی: افزایش InpMaxConsecutiveDownBars
3. برای اصلاح‌های عمیق‌تر: افزایش InpPullbackLimit
4. برای روندهای ضعیف‌تر: کاهش InpMinUpBarsPercent
